# Read log files

Read log files

## Usage

``` r
read_log(path, window, search_line)
```

## Arguments

- path:

  string: path to the log files

- window:

  integer: specifies the size of the search window in the log files.

- search_line:

  string: Custom message to search for in log file

## Value

success_file string of latest filename that successfully ran.
