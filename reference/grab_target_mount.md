# Grab the mount for the current EPI pipeline.

Grabs and returns the current mount for the EPI pipeline.

## Usage

``` r
grab_target_mount(..., p_e = pipeline_env, call = parent.frame())
```

## Arguments

- ...:

  For internal use. Leave empty.

- p_e:

  For internal use. The hidden pipeline state environment.

- call:

  For internal use. Used for error tracing.

## Value

A string in the form of "rivm"
