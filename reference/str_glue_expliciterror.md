# string glue explicit error

Helper function, used for wrapping explicit errors used in:
conf_register_object

## Usage

``` r
str_glue_expliciterror(..., sep = "", .envir = parent.frame())
```

## Arguments

- ...:

  Additional arguments. Should be empty.

- sep:

  String: Seperator

- .envir:

  Object: the parent environment from return_env, internal - do not use

## Value

Error
