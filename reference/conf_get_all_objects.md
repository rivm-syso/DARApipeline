# Get all objects

Helper function to get all objects

## Usage

``` r
conf_get_all_objects(conf_relations, conf_definitions, .call = parent.frame())
```

## Arguments

- conf_relations:

  yaml: loaded yaml containing object relations from configuration file

- conf_definitions:

  yaml: loaded yaml containing object definitions from configuration
  file

- .call:

  Object: the parent environment from return_env, internal - do not use

## Value

combined objects
