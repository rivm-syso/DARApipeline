# Parse date for get sp data

Helper function to correctly parse date objects

## Usage

``` r
get_sp_data_parse_date(d, call = parent.frame())
```

## Arguments

- d:

  Date: Date object that could be either character, Date or POSIXct
  format

- call:

  Object: the parent environment from return_env, internal - do not use

## Value

formatted date
