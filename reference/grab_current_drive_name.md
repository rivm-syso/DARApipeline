# Grab the drive_name for the current EPI pipeline.

Part of the experimental pipeline functions.

## Usage

``` r
grab_current_drive_name(..., p_e = pipeline_env, call = parent.frame())
```

## Arguments

- ...:

  For internal use. Leave empty.

- p_e:

  For internal use. The hidden pipeline state environment.

- call:

  For internal use. Used for error tracing.

## Value

A string in with the drive name
