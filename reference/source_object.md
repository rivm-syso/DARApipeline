# Source object

helper function that sources the target objects.

## Usage

``` r
source_object(object_name, p_e, return_env = .GlobalEnv, call = parent.frame())
```

## Arguments

- object_name:

  Character: the name of the object

- p_e:

  Object: package_environment, internal - do not use

- return_env:

  Object: the function execution environment, internal - do not use

- call:

  Object: the parent environment from return_env, internal - do not use
