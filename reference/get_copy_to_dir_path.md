# Get the copy to dir path from object_definitions

Retrieve the given location under `copy_to_file_path` in
object_definitions.yaml.

## Usage

``` r
get_copy_to_dir_path(data_asset_name, p_e, call = parent.frame())
```

## Arguments

- data_asset_name:

  Character.

- p_e:

  For internal use. The hidden pipeline state environment.

- call:

  For internal use. Used for error tracing.

## Value

string with filepath to copy to
