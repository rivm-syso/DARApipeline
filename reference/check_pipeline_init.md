# Check pipeline init

Helper function to check pipeline used in:

- grab_target_list

- grab_current_drive_name

- grab_target_mount

- grab_run_timestamp

- grab_object_table

- pipeline_vis

- pipeline_status

## Usage

``` r
check_pipeline_init(p_e = pipeline_env, call = parent.frame())
```

## Arguments

- p_e:

  Object: package_environment, internal - do not use

- call:

  Object: the parent environment from return_env, internal - do not use

## Value

call
