# Import object

Helper function that imports the object.

## Usage

``` r
import_object(data_asset_name, p_e, call = parent.frame())
```

## Arguments

- data_asset_name:

  Character. Name of the data_asset (objects/other) that you want to
  import object for.

- p_e:

  Object: package_environment, internal - do not use

- call:

  Object: the parent environment from return_env, internal - do not use
