# open SP

open SP

## Usage

``` r
open_sp(con, sp_name, start_date, end_date, infection_code)
```

## Arguments

- con:

  Object: connection object

- sp_name:

  string: Name of the database

- start_date:

  Date: start date for the query

- end_date:

  Date: end date for the query

- infection_code:

  string: infection code

## Value

data
